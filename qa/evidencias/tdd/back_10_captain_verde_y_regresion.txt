Conversation Assignment API
  POST /api/v1/accounts/{account.id}/conversations/<id>/assignments
    when it is an unauthenticated user
      returns unauthorized
    when it is an authenticated bot with out access to the inbox
      returns unauthorized
    when it is an authenticated user with access to the inbox
      assigns a user to the conversation
      assigns an agent bot to the conversation
      assigns a team to the conversation
    when it is an authenticated bot with access to the inbox
      assignment of an agent in the conversation by bot agent
      assignment of an team in the conversation by bot agent
    when conversation already has an assignee
      unassigns the assignee from the conversation
    when conversation already has a team
      unassigns the team from the conversation
